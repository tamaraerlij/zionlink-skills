# ZionLink Market Entry

A Claude plugin that guides you through five short steps: a first market entry plan, then a map of the commercial work your team repeats and which tasks are good candidates for Claude. You approve each step. Everything it writes is a hypothesis to test. It never sends a message for you.

Steps: `start`, `customer-profile`, `priority-countries`, `targets-and-partners`, `first-approach`, `workflow-map`, and `plan-pdf` to export your approved plan as a PDF.

Install in Claude Code:

```
claude plugin marketplace add tamaraerlij/zionlink-skills
claude plugin install zionlink-market-entry@zionlink
```

Then open a new conversation and type `/zionlink-market-entry:start`.
